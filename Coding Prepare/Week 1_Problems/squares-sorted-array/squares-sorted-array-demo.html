Squares of a Sorted Array

A Clear Guide to the Two-Pointer Method

💡 The Core Idea

When we square numbers in a sorted array like [-10, -2, 3], the result is [100, 4, 9], which is not sorted.

The key insight is that the largest squared value must come from either the first or the last number in the original sorted array.

We can use this fact to build the new sorted array from largest to smallest without having to sort at the end.

🧠 What You Must Remember: The Algorithm

  1. Set up two pointers: a left pointer at the start of the input array and a right pointer at the end.
  2. Create a new result array, but prepare to fill it from the **end to the beginning**.
  3. Compare and place: Compare the squared values at the left and right pointers. Whichever is bigger is the largest remaining square, so place it at the current end of the result array.
  4. Move the pointers: If the left side's square was bigger, move the left pointer one step to the right. Otherwise, move the right pointer one step to the left. Also, move the position in the result array one step to the left.
  5. Repeat until the pointers cross.
