📋 Problem: Product of Array Except Self

Problem Statement

Given: An integer array nums

Return: An array output where output[i] is the product of all elements except nums[i]

Constraint: You must solve it in O(n) time and without using division

Follow-up: Can you solve it with O(1) extra space? (Output array doesn't count)


Example:

Input: nums = [1, 2, 3, 4]

Output: [24, 12, 8, 6]

Explanation:

• output[0] = 2 × 3 × 4 = 24 (everything except 1)

• output[1] = 1 × 3 × 4 = 12 (everything except 2)

• output[2] = 1 × 2 × 4 = 8 (everything except 3)

• output[3] = 1 × 2 × 3 = 6 (everything except 4)

💡 More Examples:

✅ nums = [-1, 1, 0, -3, 3] → Output: [0, 0, 9, 0, 0]
✅ nums = [2, 3, 4, 5] → Output: [60, 40, 30, 24]
🎯 Core Concepts
🔑 Concept #1: Prefix Product (Left Array) ▼

Prefix Product (Left) = The accumulated product of all elements from the beginning up to AND INCLUDING index i


Example: [1, 2, 3, 4]

  • left[0] = 1 (just nums[0])
  • left[1] = 1 × 2 = 2 (product from 0 to 1, INCLUDING index 1)
  • left[2] = 1 × 2 × 3 = 6 (product from 0 to 2, INCLUDING index 2)
  • left[3] = 1 × 2 × 3 × 4 = 24 (product from 0 to 3, INCLUDING index 3)

✓ Key Point: left[i] INCLUDES nums[i] in the product!
left = [1, 2, 6, 24]
🔑 Concept #2: Suffix Product (Right Array) ▼

Suffix Product (Right) = The accumulated product of all elements from index i to the end, INCLUDING index i


Example: [1, 2, 3, 4]

  • right[3] = 4 (just nums[3])
  • right[2] = 3 × 4 = 12 (product from 2 to end, INCLUDING index 2)
  • right[1] = 2 × 3 × 4 = 24 (product from 1 to end, INCLUDING index 1)
  • right[0] = 1 × 2 × 3 × 4 = 24 (product from 0 to end, INCLUDING index 0)

✓ Key Point: right[i] INCLUDES nums[i] in the product!
right = [24, 24, 12, 4]
🔑 Concept #3: The Magic Formula ▼

The Key Insight:

output[i] = left[i-1] × right[i+1]

= (product of everything from 0 to i-1) × (product of everything from i+1 to end)

= product of everything EXCEPT nums[i] ! 🎉

Example at index 2:

  • left[i-1] = left[1] = 2 (product of [1, 2])
  • right[i+1] = right[3] = 4 (product of [4])
  • output[2] = 2 × 4 = 8 ✅ (product of [1, 2, 4] - everything except nums[2]=3)

⚠️ Boundary Cases:
• output[0] = right[1] (no left elements)
• output[n-1] = left[n-2] (no right elements)
🔑 Concept #4: O(1) Space Optimization (In-Place Magic) ▼

Naive Approach: Create two arrays (left + right) → O(n) extra space


Optimized Approach: Use the output array itself! 🔥


💡 The Brilliant Trick:

Phase 1: Calculate left array and store in output: output = [1, 2, 6, 24]
Phase 2: Traverse right-to-left, calculate right products on-the-fly, and use formula:
output[i] = output[i-1] × running_right_product

Result: No extra arrays needed! Space: O(1) ✅

How it works:

  1. First Pass (Left → Right): Build left array in output
  2. Second Pass (Right → Left): Use output[i] = output[i-1] × product
  3. Result: output[i] = left[i-1] × right[i+1] !
⏱️ Complexity Analysis
Time Complexity: O(n) - Two passes through the array (left pass + right pass)
Space Complexity: O(1) - Only using a single variable to track running product (output array doesn't count as extra space)

🎓 Why In-Place Works

The Brilliant Optimization 💡

Instead of creating TWO arrays (left + right)...

Phase 1: Store left array in output:
product *= nums[i]; output.append(product)
Result: output = [1, 2, 6, 24]

Phase 2: Traverse right-to-left with formula output[i] = output[i-1] × product:

  • i=3: product=1, output[3] = output[2] × 1 = 6 × 1 = 6, then product=4
  • i=2: product=4, output[2] = output[1] × 4 = 2 × 4 = 8, then product=12
  • i=1: product=12, output[1] = output[0] × 12 = 1 × 12 = 12, then product=24
  • i=0: product=24, output[0] = product = 24

Result: output = [24, 12, 8, 6] with O(1) extra space! 🚀

✅ Complete Solution
🎯 O(1) Space Solution Optimal 
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        """
        Calculate product of array except self using O(1) extra space.

        Approach: Two-phase computation
        - Phase 1: Build left (prefix) array in output
        - Phase 2: Multiply with right (suffix) products on-the-fly

        Time Complexity: O(n) - Two passes through array
        Space Complexity: O(1) - Only using output array (doesn't count)
        """
        length = len(nums)
        output = []

        # Edge case
        if length < 1:
            return output

        # ═══════════════════════════════════════════════════════
        # PHASE 1: Build LEFT (prefix) array in output
        # left[i] = product of nums[0] to nums[i] (INCLUSIVE)
        # ═══════════════════════════════════════════════════════
        product = 1
        for i in range(length):
            product *= nums[i]       # Multiply FIRST
            output.append(product)   # Then append (includes nums[i])

        # After Phase 1: output = [1, 2, 6, 24] for [1,2,3,4]
        # This is the LEFT array where left[i] includes nums[i]

        # ═══════════════════════════════════════════════════════
        # PHASE 2: Traverse backwards, apply formula:
        # output[i] = left[i-1] × right[i+1]
        # ═══════════════════════════════════════════════════════
        product = 1
        for i in range(length - 1, 0, -1):  # From n-1 down to 1
            output[i] = output[i-1] * product  # left[i-1] × right[i+1]
            product *= nums[i]               # Update running right product

        # Handle output[0] separately (no left elements)
        output[0] = product

        # After Phase 2: output = [24, 12, 8, 6]

        return output

🎯 Key Implementation Details
✅ Phase 1: Build Left Array in Output ▼
Phase 1 Explanation 
product = 1
for i in range(length):
    product *= nums[i]      # Multiply FIRST (include current element)
    output.append(product)  # Then append to output

# Example trace for [1, 2, 3, 4]:
# i=0: product=1*1=1, output=[1]
# i=1: product=1*2=2, output=[1,2]
# i=2: product=2*3=6, output=[1,2,6]
# i=3: product=6*4=24, output=[1,2,6,24]
# Result: output = LEFT array = [1, 2, 6, 24]

✓ Critical: We multiply nums[i] BEFORE appending, so output[i] contains the product from index 0 to i INCLUDING nums[i]!
✅ Phase 2: Apply Formula with Right Products ▼
Phase 2 Explanation 
product = 1  # Tracks right[i+1]
for i in range(length - 1, 0, -1):  # From n-1 down to 1
    output[i] = output[i-1] * product  # left[i-1] × right[i+1]
    product *= nums[i]                 # Update for next iteration

output[0] = product  # Special case: no left elements

# Example trace for [1, 2, 3, 4] with output=[1,2,6,24]:
# i=3: output[3]=output[2]*1=6*1=6, product=1*4=4
#      (left[2] × right[4], but right[4] doesn't exist so =1)
# i=2: output[2]=output[1]*4=2*4=8, product=4*3=12
#      (left[1] × right[3] = 2 × 4 = 8) ✅
# i=1: output[1]=output[0]*12=1*12=12, product=12*2=24
#      (left[0] × right[2] = 1 × 12 = 12) ✅
# After loop: output[0]=24 (right[1] = 24)
# Final: output=[24,12,8,6] ✅

✓ The Magic: output[i-1] contains left[i-1], and product contains right[i+1]. Multiplying them gives us the answer!
⚠️ Common Pitfalls ▼
❌ Mistake #1: Appending before multiplying in Phase 1
output.append(product); product *= nums[i]
This creates [1, 1, 2, 6] instead of [1, 2, 6, 24]!
❌ Mistake #2: Wrong loop range in Phase 2
Must go from length-1 down to 1 (not 0)!
Handle output[0] separately.
❌ Mistake #3: Not resetting product = 1 between phases
Each phase needs fresh product = 1!
