📋 Problem: Longest Substring with K Distinct Characters

Problem Statement

Given: A string s and an integer k

Find: The length of the longest substring with at most K distinct characters


Example:

Input: s = "araaci", k = 2

Output: 4

Explanation: The longest substring is "araa" with only 2 distinct characters ('a' and 'r')

💡 More Examples:

✅ s = "aaab", k = 1 → Output: 3 (substring "aaa")
✅ s = "cbbebi", k = 3 → Output: 5 (substring "cbbeb")
✅ s = "abcdef", k = 2 → Output: 2 (any two adjacent chars)
🎯 Core Concepts
🔑 Concept #1: Sliding Window (Variable Size) ▼

This is a longest valid window problem using the variable-size sliding window pattern.


How it works:

  • Expand: Move right pointer, add new characters
  • Shrink: When invalid (>K distinct), move left pointer
  • Track: Update maximum length during valid states

✓ Why Variable Size? The window grows and shrinks dynamically based on the validity condition. We don't know the answer size beforehand!
🔑 Concept #2: Hash Map for Frequency Tracking ▼

You MUST use a hash map (dictionary), NOT a set!


❌ SET (Wrong)

• Only tracks presence/absence
• Can't count frequencies
• Loses track when character removed
• Fails when chars repeat in window
✅ HASH MAP (Correct)

• Tracks character frequencies
• Counts how many times each appears
• Only removes when count = 0
• Works perfectly with repeating chars
🔑 Concept #3: Validity Condition ▼

Valid Window: len(freq_map) ≤ K

Invalid Window: len(freq_map) > K


When Invalid:

  • Shrink from left by moving left pointer
  • Decrease character count: freq[char] -= 1
  • Remove from map only when: freq[char] == 0
  • Repeat until valid again
🔑 Concept #4: Algorithm Flow ▼
📝 Pseudocode 
freq = {}
left = 0
max_length = 0

for right in range(len(string)):
    # 1. Expand: Add character at right
    freq[string[right]] += 1

    # 2. Shrink: While invalid
    while len(freq) > k:
        freq[string[left]] -= 1
        if freq[string[left]] == 0:
            del freq[string[left]]
        left += 1

    # 3. Track: Update maximum
    max_length = max(max_length, right - left + 1)

return max_length
⏱️ Complexity Analysis
Time Complexity: O(n) - Each character is visited at most twice (once by right, once by left)
Space Complexity: O(k) - Hash map stores at most K+1 distinct characters

🎯 Why HashMap and NOT Set?
⚠️ The #1 Most Common Mistake: Using set() instead of a hash map. This approach FAILS for the K Distinct problem!
💡 The Key Question

Ask Yourself This:

"Can a character appear MULTIPLE TIMES in a valid window?"

✅ NO → Each character appears AT MOST ONCE → Use SET
✅ YES → Characters CAN repeat in the window → Use HASH MAP

🔍 Understanding Through Two Problems
Problem 1: Longest Substring WITHOUT Repeating Characters ▼
Goal: Find longest substring where NO character repeats
Example: "abcda" → Answer is "abcd" (length 4)

Question: Can 'a' appear twice in a valid window?

Answer: ❌ NO! If 'a' appears twice, the window is INVALID.

💡 The "Aha" Moment:

Since each character can appear AT MOST ONCE in a valid window:
• When you remove 'a' from the window, you're removing the ONLY 'a'
• Removing from SET = Removing ALL instances (because there's only 1!)
• ✅ SET works perfectly!
✅ Using SET (Correct for this problem) 
def lengthOfLongestSubstring(s):
    seen = set()  # ✅ SET works here!
    left = 0
    max_len = 0

    for right in range(len(s)):
        # If duplicate found, shrink until it's gone
        while s[right] in seen:
            seen.remove(s[left])  # Remove the ONLY copy
            left += 1

        seen.add(s[right])
        max_len = max(max_len, right - left + 1)

    return max_len

Why SET works:

  • SET tracks: "Is this character currently in my window?"
  • When we remove 'a', there are NO more 'a's left (it only appeared once!)
  • We can safely "forget" about 'a' completely
🎬 Example Trace: "abcda"

Window "abcd", seen = {a, b, c, d}
→ Try to add 'a' at index 4
→ 'a' is in seen! Duplicate! 🚨
→ Remove left: seen.remove('a') → seen = {b, c, d}
→ Move left pointer forward
→ 'a' is now gone from seen (and gone from window!)
→ Add new 'a': seen = {b, c, d, a} ✅
Problem 2: Longest Substring with K Distinct Characters ▼
Goal: Find longest substring with AT MOST K distinct characters
Example: "aaabbc" with k=2 → Answer is "aaabb" (length 5)

Question: Can 'a' appear multiple times in a valid window?

Answer: ✅ YES! "aaabb" has three 'a's and is still valid (only 2 distinct chars).

🔴 The Problem with SET:

Since characters CAN repeat in a valid window:
• When you remove 'a' from SET, you lose ALL tracking of 'a'
• But there might be OTHER 'a's still in the window!
• ❌ SET gives WRONG information!
❌ Using SET (WRONG for this problem) BUGGY 
def findLength(str1, k):
    seen = set()  # ❌ WRONG!
    start = 0
    max_length = 0

    for end in range(len(str1)):
        seen.add(str1[end])

        while len(seen) > k:
            seen.remove(str1[start])  # 🔴 BUG: Loses tracking!
            start += 1

        max_length = max(max_length, end - start + 1)

    return max_length
🎬 Example: Why SET fails for "aaabbc" with k=2

Step 1-4: Window = "aaab", seen = {a, b} ✅ (2 distinct, valid)
Step 5: Add 'b' → Window = "aaabb", seen = {a, b} ✅ (2 distinct, valid)
Step 6: Add 'c' → Window = "aaabbc", seen = {a, b, c} ❌ (3 distinct, INVALID!)

Shrink: Remove str[0]='a' → seen.remove('a') → seen = {b, c}

🚨 THE BUG:
• Window is now "aabbc" (indices 1-5)
• Actual characters: a, a, b, b, c = 3 distinct ❌
• SET says: {b, c} = 2 distinct ✓

The SET lost track of the TWO 'a's that are STILL IN THE WINDOW!
✅ Using HASH MAP (Correct) CORRECT 
def findLength(str1, k):
    freq = {}  # ✅ Hash map tracks frequencies!
    start = 0
    max_length = 0

    for end in range(len(str1)):
        char = str1[end]
        freq[char] = freq.get(char, 0) + 1  # Count increases

        while len(freq) > k:
            left_char = str1[start]
            freq[left_char] -= 1  # Decrease count

            # ✅ Only delete when count reaches 0!
            if freq[left_char] == 0:
                del freq[left_char]

            start += 1

        max_length = max(max_length, end - start + 1)

    return max_length
🎬 Correct trace: "aaabbc" with k=2

Step 6: Window = "aaabbc", freq = {a:3, b:2, c:1} ❌ (3 distinct, INVALID!)

Shrink: Remove 'a' → freq[a] = 3-1 = 2 → freq = {a:2, b:2, c:1} ❌ Still 3 distinct!
Shrink: Remove 'a' → freq[a] = 2-1 = 1 → freq = {a:1, b:2, c:1} ❌ Still 3 distinct!
Shrink: Remove 'a' → freq[a] = 1-1 = 0 → DELETE 'a' → freq = {b:2, c:1} ✅ 2 distinct!

Window is now "bbc" (indices 3-5) with 2 distinct characters ✅

🎓 Mental Model
SET = Light Switch 💡

• ON or OFF (present or absent)
• "Is 'a' in my window?"
• Can't count how many
• Perfect when items appear once
HASH MAP = Counter 🔢

• Tracks exact count
• "How many 'a's in my window?"
• Only delete when count = 0
• Needed when items can repeat
✅ The Golden Rule

Before Choosing Your Data Structure:

Ask: "Can an element appear MULTIPLE times in a valid state?"

🔹 NO (each appears at most once) → SET is sufficient
🔹 YES (elements can repeat) → HASH MAP required


This rule applies to MANY coding problems, not just sliding window!

class Solution:
    def findLength(self, str1: str, k: int) -> int:
        """
        Find the length of the longest substring with at most K distinct characters.

        Args:
            str1: Input string
            k: Maximum number of distinct characters allowed

        Returns:
            Length of longest valid substring

        Time Complexity: O(n) - each character visited at most twice
        Space Complexity: O(k) - hash map stores at most K+1 characters

        Example:
            >>> Solution().findLength("araaci", 2)
            4
            >>> Solution().findLength("aaab", 1)
            3
        """
        # Edge case: empty string or k = 0
        if not str1 or k == 0:
            return 0

        freq = {}  # Character → frequency count
        left = 0
        max_length = 0

        for right in range(len(str1)):
            # Expand window: add character at right pointer
            char = str1[right]
            freq[char] = freq.get(char, 0) + 1

            # Shrink window while invalid (too many distinct characters)
            while len(freq) > k:
                left_char = str1[left]
                freq[left_char] -= 1

                # Remove character from map only when count reaches 0
                if freq[left_char] == 0:
                    del freq[left_char]

                left += 1

            # Update result (window is valid here)
            max_length = max(max_length, right - left + 1)

        return max_length

🎯 Key Points to Remember
✅ Algorithm Steps ▼
  1. Initialize: freq = {}, left = 0, max_length = 0
  2. Expand: For each right pointer, add char and increase frequency
  3. Shrink: While len(freq) > k, remove from left and decrease frequency
  4. Delete: Only remove from freq when count becomes 0
  5. Track: Update max_length when window is valid
⚠️ Common Pitfalls ▼
❌ Don't use set() instead of dict()
Sets can't track frequencies!
❌ Don't forget to delete when count = 0
Always check: if freq[char] == 0: del freq[char]
❌ Don't update result inside shrink loop
Update after shrinking when window is valid
