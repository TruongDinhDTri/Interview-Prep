The Two Pointers pattern is a fundamental algorithmic technique used to solve array and string problems efficiently. Instead of using nested loops (O(n²)), we can often solve problems in O(n) time using two strategically positioned pointers.

💡 What is the Two Pointers Pattern?

The Two Pointers pattern involves using two references (pointers) to traverse a data structure, typically an array. The pointers can move:

  • Toward each other - One from the start, one from the end
  • In the same direction - One fast, one slow (sliding window)
  • Independently - Based on specific conditions

Why use it? It reduces time complexity from O(n²) to O(n) and uses O(1) space!
