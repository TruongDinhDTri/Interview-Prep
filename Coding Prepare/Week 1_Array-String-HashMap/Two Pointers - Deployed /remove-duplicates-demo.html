🎯 Remove Duplicates from Sorted Array

A Complete Visual Guide with Core Concepts

💡 The Core Idea (READ THIS FIRST!)

We use TWO POINTERS:

  • 🔵 Scanner (i) = Reads through EVERY element in the array
  • 🟢 Next Position (nextNonDuplicate) = Marks WHERE to put the next unique number

The Strategy: Scanner looks for NEW numbers. When it finds one, we copy it to the "next position" and move that position forward.

📚 What You MUST Remember

✅ Key Points to Remember

  • Array is SORTED - All duplicates are next to each other: [2, 3, 3, 3, 6]
  • nextNonDuplicate starts at 1 - Because arr[0] is always unique (it's the first!)
  • We compare with arr[nextNonDuplicate - 1] - This is the LAST unique number we found
  • Scanner (i) ALWAYS moves forward - It checks every element
  • nextNonDuplicate only moves when we find NEW number - It stays still for duplicates

🎯 What Needs to be Done (The Algorithm)

  1. Start: Set nextNonDuplicate = 1 (position for next unique)
  2. Loop: Use i to scan from index 1 to end
  3. Compare: Is arr[i] different from arr[nextNonDuplicate - 1]?
  4. If YES (new number): Copy arr[i] to arr[nextNonDuplicate], then nextNonDuplicate++
  5. If NO (duplicate): Do nothing, just move i forward
  6. Return: nextNonDuplicate is the count of unique elements

❌ Common Mistakes to Avoid

❌ WRONG:
for i in arr[1:]: # i is a VALUE (3, 3, 6...) # Can't use arr[i]!
✅ CORRECT:
for i in range(1, len(arr)): # i is an INDEX (1, 2, 3...) # Can use arr[i]!
  • Don't compare arr[i] with arr[nextNonDuplicate] - Compare with arr[nextNonDuplicate - 1]
  • Don't start nextNonDuplicate at 0 - Start at 1 (arr[0] is already unique)
  • Don't forget to increment nextNonDuplicate after copying

💻 The Code (Python)

def removeDuplicates(arr):
    # Step 1: Handle edge case
    if len(arr) == 0:
        return 0

    # Step 2: Initialize nextNonDuplicate
    # arr[0] is always unique, so start at 1
    nextNonDuplicate = 1

    # Step 3: Loop through array with scanner (i)
    for i in range(1, len(arr)):

        # Step 4: Compare current with last unique
        # arr[nextNonDuplicate - 1] = last unique number
        if arr[i] != arr[nextNonDuplicate - 1]:

            # Step 5: Found NEW number! Copy it
            arr[nextNonDuplicate] = arr[i]

            # Step 6: Move nextNonDuplicate forward
            nextNonDuplicate += 1

    # Step 7: Return count of unique elements
    return nextNonDuplicate


# Example usage:
arr = [2, 3, 3, 3, 6, 9, 9]
length = removeDuplicates(arr)
print(f"Unique count: {length}")  # Output: 4
print(f"Unique array: {arr[:length]}")  # Output: [2, 3, 6, 9]

🧠 Why This Works

The Logic Behind It

Since the array is sorted, all duplicates are grouped together:

[2, 3, 3, 3, 6, 9, 9] ^ ^-----^ ^ ^--^ first dups first dups

We only need to check if the current number is different from the previous unique number:

  • If different → It's a NEW unique number, copy it!
  • If same → It's a duplicate, skip it!

Time & Space Complexity

  • Time: O(n) - We scan through the array once
  • Space: O(1) - We only use two pointers, no extra arrays

📝 Practice Tips

  1. Trace by hand first: Write out the array and manually track i and nextNonDuplicate
  2. Remember the pattern: Scanner (fast) + Next Position (slow) = Two Pointer Pattern
  3. Ask yourself: "Is this number different from the last unique?" That's the key question!
  4. Don't overthink: The sorted property makes this simple - duplicates are always neighbors
