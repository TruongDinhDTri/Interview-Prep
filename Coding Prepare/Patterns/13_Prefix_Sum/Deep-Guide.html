Pattern 13

PrefixSum.

One core idea — precompute running totals once, then any range sum is a single subtraction. Press step and watch.

The core idea

Like a car's odometer.

On a road trip, to know the distance between mile-marker 1 and mile-marker 3 you don't re-drive that stretch — you read the odometer at each and subtract. Prefix sum is that odometer for an array: at every point you record the total so far.

Want the sum of indices 1…3 (the 4, 1, 3)? Don't re-add them. Take the odometer reading after index 3 and subtract the reading before index 1: 10 − 2 = 8. Any range, one subtraction, O(1).

Record the running total; a range sum is the difference of two readings. Build the odometer once in O(n), then every range query is O(1): prefix[j+1] − prefix[i]. The leading 0 is the “start of the trip” reading that makes ranges from index 0 work.

Shape one of two

① Range query — sum i…j in O(1).

Static array · many queries

Range query

Build the prefix array once. Each “sum from i to j” becomes prefix[j+1] − prefix[i] — the big total minus the part you don't want.

The idea

Think of prefix[k] as “distance travelled by step k.” The distance covered between two checkpoints is just the difference of the two odometer readings — no need to re-walk the road.

The movement — build, then subtract

Array [2, 4, 1, 3, 5]; query sum of indices 1…3.

array
prefix · prefix[k] = sum before k

The code

def build(nums):
    prefix = [0]
    for num in nums:
        prefix.append(prefix[-1] + num)   # running total
    return prefix
# sum of nums[i..j]  =  prefix[j+1] - prefix[i]   (O(1))

Lives in: range-sum queries · running averages · 2-D prefix (image region sums).

Shape two of two

② Prefix + hash — count subarrays = K.

Counting · running sum + map

Prefix + hash map

A subarray sums to K exactly when prefix[j+1] − prefix[i] = K, i.e. some earlier prefix equals curr − K. So as you sweep, ask a hash map “how many earlier prefixes equal curr − K?”

The idea

One pass, one running sum, one map of prefix → count. At each step, add map[curr − K] to the answer (those are subarrays ending here that sum to K), then record the current prefix. Seed the map with {0: 1} so subarrays starting at index 0 are counted.

The movement — the map answers

Count subarrays summing to K = 3 in [1, 2, 1, 2].

The code

def subarray_sum(nums, k):
    seen = {0: 1}        # empty prefix once — handles start at 0
    curr = count = 0
    for num in nums:
        curr += num
        count += seen.get(curr - k, 0)   # earlier prefixes that close a K-sum
        seen[curr] = seen.get(curr, 0) + 1
    return count

Lives in: subarray sum = K · count subarrays · “contiguous array” (treat 0 as −1, find sum 0).

Range query = build totals once, subtract for any range. Prefix + hash = sweep once, ask the map for the matching earlier prefix. Same root: a range sum is a difference of two running totals.

You own it when…

The test.

  • Core idea in one line: range sum = prefix[j+1] − prefix[i].
  • You always seed the count map with {0: 1}.
  • You spot “count subarrays with sum K” → prefix + hash, asking for curr − K.
  • “Longest/shortest with a constraint” → Sliding Window; “exact sum count” → Prefix + Hash.
