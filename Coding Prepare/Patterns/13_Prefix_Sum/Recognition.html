Pattern 13 · Recognition

Prefix Sum

⚡ Thẻ nhận diện nhanh — liếc signal là ra bài.

🎯 Spot it

The signals that scream Prefix Sum.

Repeated "sum from i to j" or "subarray sum equals K" on a fixed array — precompute running totals once, answer each query in O(1).

Thấy hỏi "tổng đoạn i→j" nhiều lần hoặc "đếm subarray tổng = K" trên mảng cố định → dựng mảng tổng dồn trước, mỗi truy vấn trả lời tức thì.
"range sum query" / "sum from i to j"✓ prefix sum
"subarray sum equals K"✓ + hash map
"count subarrays with sum K"✓ + hash map
Array changes frequently (updates)✗ → segment tree
Bài tổng đoạn / đếm subarray có tổng = K trên mảng đứng yên → Prefix Sum (loại đếm thì ghép thêm Hash Map). Nhưng mảng bị sửa liên tục thì đổi sang Segment Tree.

⚙️ Why it works

One precompute buys O(1) range queries. Let prefix[i] = sum of elements 0..i-1. Then the sum from i to j = prefix[j+1] - prefix[i]. Build once in O(n), answer any range in O(1) forever after.
Cộng dồn một lần từ đầu mảng; tổng của đoạn bất kỳ chỉ là hiệu hai mốc tổng dồn. Trả tiền O(n) một lần, sau đó mỗi câu hỏi tổng đoạn là O(1).

💻 The core

The move, in code.

Build the prefix array.

def buildPrefix(nums):
    prefix = [0]
    for num in nums:
        prefix.append(prefix[-1] + num)
    return prefix

# Sum from index i to j (inclusive):
# prefix[j+1] - prefix[i]

Count subarrays with sum = K — prefix sum meets a hash map.

def subarraySum(nums, k):
    prefix_count = {0: 1}
    curr_sum = 0
    count = 0
    for num in nums:
        curr_sum += num
        # How many prefix sums = curr_sum - k?
        count += prefix_count.get(curr_sum - k, 0)
        prefix_count[curr_sum] = prefix_count.get(curr_sum, 0) + 1
    return count
Cách 1: dựng mảng tổng dồn rồi lấy hiệu để ra tổng đoạn. Cách 2 (đếm subarray = K): vừa đi vừa hỏi "đã từng gặp tổng dồn nào = curr_sum − k chưa?" — Hash Map trả lời trong O(1).

⚠️ Traps

Where it breaks.

  1. Seed the map with {0: 1} — handles subarrays that start at index 0.
  2. prefix[j+1] - prefix[i] — mind the off-by-one on the indices.
  3. "Contiguous Array" (0s and 1s): treat every 0 as -1, then hunt for a subarray with sum 0.
Ba cái bẫy: (1) quên seed {0:1} → sót đoạn bắt đầu từ đầu mảng; (2) lệch chỉ số ở công thức hiệu; (3) bài 0/1 thì biến 0 thành −1 rồi tìm đoạn tổng = 0.
