Pattern 09 · Recognition

Merge Intervals

⚡ Thẻ nhận diện nhanh — liếc signal là ra bài.

🎯 Spot it

The signals that scream Merge Intervals.

A list of [start, end] intervals + the words overlap / merge / meeting rooms.

Thấy một dãy khoảng [đầu, cuối] mà đề nói "chồng nhau / gộp / phòng họp" → bật Merge Intervals ngay.
"merge overlapping intervals"✓ merge intervals
"meeting rooms" / scheduling conflicts✓ merge intervals
"insert interval" into a sorted list✓ merge intervals
Cả ba dấu hiệu đều là khoảng thời gian đè lên nhau — gộp lại, chèn vào, hay đếm phòng. Nghe thấy "interval" + "overlap" là gần như chắc chắn.

⚙️ Why it works

Sort by start time. Then each interval can only overlap with the previous one — never one further back. Check & merge in a single pass → O(n log n) (the sort dominates). Overlap condition: curr.start <= prev.end.
Sort theo điểm bắt đầu xong thì mỗi khoảng chỉ cần so với thằng liền trước — không phải ngó lại cả đám. Nhờ vậy một vòng quét là gộp xong.

💻 The core

The move, in code.

def merge(intervals):
    intervals.sort(key=lambda x: x[0])
    result = [intervals[0]]

    for curr in intervals[1:]:
        prev = result[-1]
        if curr[0] <= prev[1]:          # overlap
            prev[1] = max(prev[1], curr[1])   # merge
        else:
            result.append(curr)

    return result

Meeting Rooms II (min rooms needed) — a Line Sweep instead of a merge:

def minRooms(intervals):
    events = []
    for start, end in intervals:
        events.append((start, 1))    # +1 at start
        events.append((end, -1))     # -1 at end
    events.sort()

    curr = max_rooms = 0
    for time, delta in events:
        curr += delta
        max_rooms = max(max_rooms, curr)
    return max_rooms
Gộp thì sort rồi so với thằng trước. Còn đếm số phòng thì tách mỗi khoảng thành 2 sự kiện +1/−1, quét qua đếm cao điểm — đó là Line Sweep.

⚠️ Traps

Where it breaks.

  1. Sort first — always. Without sorting by start, the "only overlaps previous" rule falls apart.
  2. Merge uses max(prev.end, curr.end) — curr might be fully contained inside prev, so don't just take curr.end.
  3. Meeting Rooms I vs II: I = "is there ANY overlap?" (boolean), II = "min rooms needed" (line sweep). Different questions.
Ba cái chết người: (1) quên sort trước; (2) gộp mà quên max nên nuốt mất khoảng dài hơn; (3) lẫn Meeting Rooms I (có chồng không?) với II (cần mấy phòng?).
