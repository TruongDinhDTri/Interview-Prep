Pattern 06 · Recognition

DFS

⚡ Thẻ nhận diện nhanh — liếc signal là ra bài.

🎯 Spot it

The signals that scream DFS.

Explore EVERYTHING — all paths, all islands, whole tree — and it's NOT asking for the shortest one.

Nghe "tất cả đường / mọi tổ hợp / đếm cụm liên thông", hoặc "parent cần thông tin của con trước" → DFS. Hễ hỏi ngắn nhất thì đổi sang BFS.
"all paths" / "any path exists"✓ dfs
"connected components" / "islands"✓ dfs
"tree traversal" / "validate BST"✓ dfs
"cycle detection" / "topological sort"✓ dfs
"tree height" / "depth" / "balanced"✓ post-order
"every node must satisfy condition"✓ check on way up
"need children's info before the parent"✓ post-order
"shortest path" / "minimum steps"✗ → bfs

Key sentence (3P Match): "I see tree height / every node which tells me DFS (post-order) because each node needs its children's values FIRST before it can do its own work."

Tất cả đều là đào sâu một nhánh tới đáy rồi quay lui. Ba dòng cuối là dấu hiệu post-order: con xong trước, cha xử lý sau. Chỉ cần nghe "ngắn nhất" là chuyển BFS.

⚙️ Why it works

DFS explores ONE branch completely, then backtracks. The call stack IS your backtracking — each return pops you back to the last decision point. Time O(V+E), space O(H) where H is the recursion height.
DFS đi hết một nhánh mới quay lại. Cái call stack chính là bộ nhớ quay lui — không cần tự quản lý stack. Tốn O(V+E) thời gian, O(H) bộ nhớ theo chiều sâu đệ quy.

💻 The core

The move, in code.

Tree DFS — recurse both sides, then combine at the node:

def dfs(node):
    if not node: return BASE_VALUE

    left  = dfs(node.left)
    right = dfs(node.right)

    return COMBINE(node.val, left, right)
PROBLEM BASE COMBINE
Max Depth01 + max(L, R)
Path Sumcheck leafsubtract, recurse
Validate BSTTruepass min/max bounds down
Balanced Tree0 (None→0)-1 if unbalanced, else 1+max(L,R)

-1 Sentinel trick: when you must return height (int) AND validity (bool), use -1 as the impossible-height signal. Parent checks if left == -1 or right == -1: return -1. Outer wrapper converts: return dfs(root) != -1.

Graph DFS — same idea, but a visited set stops cycles:

def dfs(node, visited):
    if node in visited: return
    visited.add(node)

    for neighbor in graph[node]:
        dfs(neighbor, visited)

Cycle in a directed graph: use 3 colors (white / gray / black). Hitting a gray node = cycle.

Tree DFS = hỏi trái, hỏi phải, rồi COMBINE tại node — đổi bài chỉ đổi BASE và COMBINE. Graph thì thêm visited vì có chu trình. Chiêu sentinel -1 gói cả chiều cao lẫn tính hợp lệ vào một số.

⚠️ Traps

Where it breaks.

  1. Graphs need a visited set — trees don't (no cycles).
  2. Copy the path before storing: result.append(path[:]), not result.append(path) — otherwise every stored path mutates together.
  3. DFS finds A path, not THE SHORTEST — if they want shortest, that's BFS.
Ba cái chết người: (1) quên visited trên graph → lặp vô tận; (2) quên copy path → mọi kết quả bị sửa chung; (3) tưởng DFS ra đường ngắn nhất — không, đó là việc của BFS.
