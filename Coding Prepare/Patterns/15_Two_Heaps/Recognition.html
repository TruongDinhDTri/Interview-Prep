Pattern 15 · Recognition

Two Heaps

⚡ Thẻ nhận diện nhanh — liếc signal là ra bài.

🎯 Spot it

The signals that scream Two Heaps.

Find the median of streaming / dynamic data — split into a smaller half and a larger half, each in its own heap.

Tìm median của dòng dữ liệu chảy vào liên tục → cắt đôi thành nửa nhỏ + nửa lớn, mỗi nửa một heap.
"Find median" + "streaming / dynamic data"✓ two heaps
"Kth largest"✗ → single heap size K
Static data (given all at once)✗ → just sort
Median + dữ liệu đến dần → Two Heaps. Nhưng "Kth largest" chỉ cần một heap size K, còn dữ liệu tĩnh cho sẵn hết thì sort là xong.

⚙️ Why it works

The median is the border between two halves. A max-heap holds the smaller half → its root is the largest of the smalls. A min-heap holds the larger half → its root is the smallest of the larges. Keep the sizes balanced (differ by ≤ 1) and the median is sitting right on the border. Add: O(log n) · Median: O(1).
Median là đường biên giữa nửa nhỏ và nửa lớn. Max-heap giữ nửa nhỏ (gốc = lớn nhất bên nhỏ), min-heap giữ nửa lớn (gốc = nhỏ nhất bên lớn). Giữ hai bên cân bằng → median nằm ngay hai gốc.

💻 The core

The move, in code.

import heapq

class MedianFinder:
    def __init__(self):
        self.small = []   # max-heap (NEGATE values)
        self.large = []   # min-heap

    def addNum(self, num):
        # Add to correct heap
        if not self.small or num <= -self.small[0]:
            heapq.heappush(self.small, -num)
        else:
            heapq.heappush(self.large, num)

        # Rebalance
        if len(self.small) > len(self.large) + 1:
            heapq.heappush(self.large, -heapq.heappop(self.small))
        elif len(self.large) > len(self.small):
            heapq.heappush(self.small, -heapq.heappop(self.large))

    def findMedian(self):
        if len(self.small) > len(self.large):
            return -self.small[0]
        return (-self.small[0] + self.large[0]) / 2
Mỗi số đến: bỏ vào đúng nửa (nhỏ hay lớn), rồi rebalance để hai heap chênh nhau tối đa 1. Median = gốc heap lớn hơn (số lẻ) hoặc trung bình hai gốc (số chẵn).

⚠️ Traps

Where it breaks.

  1. Python has a min-heap only — negate values to build the max-heap for the smaller half.
  2. Compare with -small[0], not small[0] — the value is stored negated.
  3. Check if not self.small before comparing, or the very first element crashes.
Ba cái bẫy: (1) Python chỉ có min-heap → đảo dấu để làm max-heap; (2) so sánh phải dùng -small[0] vì giá trị đang bị âm; (3) nhớ check heap rỗng trước khi so, kẻo phần tử đầu tiên làm nổ.
