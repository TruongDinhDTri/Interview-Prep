Pattern 12 · Recognition

Top K Elements

⚡ Thẻ nhận diện nhanh — liếc signal là ra bài.

🎯 Spot it

The signals that scream Top K.

The word "K" next to largest / smallest / most frequent / Kth — keep a heap of size K, never sort the whole thing.

Nghe chữ "K" đi kèm lớn nhất / nhỏ nhất / hay gặp nhất / thứ K → bật Heap size K ngay, đừng sort cả mảng.
"K largest" / "K smallest"✓ top k
"K most frequent"✓ top k
"Kth largest element"✓ top k
"Find median"✗ → two heaps
Hễ đề hỏi K phần tử tốt nhất (to/nhỏ/hay gặp) hoặc phần tử thứ K → Top K. Nhưng nghe "median" thì đổi sang Two Heaps, đừng nhầm.

⚙️ Why it works

The root is the gatekeeper. Keep a heap of size K. The root = the worst of your current top K. A new element beats the root? Kick the root out, let the newcomer in. Top K largest → min-heap (root = smallest of the large ones); Top K smallest → max-heap (root = largest of the small ones). Cost O(n log K) — crushes sorting when K << n.
Cái heap chỉ giữ đúng K đứa; gốc heap là thằng yếu nhất trong nhóm top. Đứa mới mạnh hơn gốc thì đá gốc ra. Vì heap chỉ size K nên rẻ hơn sort cả mảng nhiều khi K nhỏ.

💻 The core

The move, in code.

import heapq

def topKLargest(nums, k):
    heap = []                       # min-heap
    for num in nums:
        heapq.heappush(heap, num)
        if len(heap) > k:
            heapq.heappop(heap)     # kick out smallest
    return heap                     # contains K largest

Kth Largest = the heap root after processing everything.

def kthLargest(nums, k):
    heap = []
    for num in nums:
        heapq.heappush(heap, num)
        if len(heap) > k:
            heapq.heappop(heap)
    return heap[0]                  # root = Kth largest

Top K Frequent — count first, then top K.

def topKFrequent(nums, k):
    count = Counter(nums)
    return heapq.nlargest(k, count.keys(), key=count.get)
Đẩy mọi phần tử vào heap, hễ heap phình quá K thì pop gốc → cuối cùng còn đúng K đứa mạnh nhất. Bài frequency thì đếm bằng Counter trước rồi mới lấy top K.

⚠️ Traps

Where it breaks.

  1. K Largest uses a MIN-heap, K Smallest uses a MAX-heap — counterintuitive, learn it cold.
  2. Python only has a min-heap — negate values (-num) to fake a max-heap.
  3. Frequency problems: count first, then top K — never heap the raw values.
Ba cái bẫy: (1) K lớn nhất lại dùng min-heap — ngược trực giác; (2) Python chỉ có min-heap → đảo dấu để giả max-heap; (3) bài tần suất phải đếm trước rồi mới lấy top K.
