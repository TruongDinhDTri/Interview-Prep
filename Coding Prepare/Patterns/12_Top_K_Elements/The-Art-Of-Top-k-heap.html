Part IV: The Negative Trick (Python)

The Problem: Python's heapq ONLY has a Min-Heap.

The Need: For Top-K Smallest, we need a Max-Heap (to kick out large numbers).
The Hack: min_heap(-x) behaves exactly like max_heap(x).

The "Mirror" World

What we WANT (Concept)

Max Heap (Positives)

Root = Largest Value

What Python DOES (Actual)

Min Heap (Negatives)

Root = Smallest (Most Negative)

The Code Spell

solution.py
import heapq

def top_k_smallest(nums, k):
# 1. The Lifeboat (Max Heap simulated with Negatives)
max_heap = []

for num in nums:
# 🔄 TRICK: Flip sign to use Min-Heap as Max-Heap
heapq.heappush(max_heap, -num)

# If boat is too full, kick out the "Heaviest" (Root)
if len(max_heap) > k:
removed = heapq.heappop(max_heap)
# 'removed' is the smallest negative (e.g. -100)
# which corresponds to largest positive (100)

# 2. Flip signs back to return result
return [-x for x in max_heap]
