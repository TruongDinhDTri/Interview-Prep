Pattern 02 · Recognition

Sliding Window

⚡ Thẻ nhận diện nhanh — liếc signal là ra bài.

🎯 Spot it

The signals that scream Sliding Window.

Contiguous subarray / substring + a constraint on the range (longest / shortest / at most K).

Nghe "subarray/substring liên tục" đi kèm một ràng buộc (dài nhất / ngắn nhất / nhiều nhất K) → bật Sliding Window ngay.
"Longest substring with at most K distinct"✓ sliding window
"Minimum length subarray with sum ≥ target"✓ sliding window
"Longest substring without repeating"✓ sliding window
"Find a pair summing to K"✗ → two pointers
Cả 3 dấu hiệu trên đều là một cửa sổ liền kề phình ra / co lại theo một ràng buộc. Nhưng hễ nghe "tìm cặp cộng ra K" → đó là Two Pointers, đừng nhầm.

⚙️ Why it works

Instead of checking every subarray in O(n²), you expand right → shrink left while invalid. Each element enters the window once and leaves once → every element is touched at most twice = O(n).
Thay vì duyệt lại mọi subarray, cửa sổ chỉ trượt một chiều: mỗi phần tử vào một lần, ra một lần → chạm tối đa 2 lần → O(n) thay cho O(n²).

💻 The core

The move, in code.

def longestWithKDistinct(s, k):
    count = {}  # char -> frequency
    left = 0
    max_len = 0

    for right in range(len(s)):
        # Expand: add s[right]
        count[s[right]] = count.get(s[right], 0) + 1

        # Shrink: while constraint violated
        while len(count) > k:
            count[s[left]] -= 1
            if count[s[left]] == 0:
                del count[s[left]]
            left += 1

        # Update answer
        max_len = max(max_len, right - left + 1)

    return max_len
Vòng for right nới cửa sổ ra; vòng while co lại khi vi phạm; mỗi bước cập nhật max_len. Đó là toàn bộ khung Sliding Window.

⚠️ Traps

Where it breaks.

  1. Shrink with while, not if — you may need multiple shrinks to become valid again.
  2. Delete the key when count hits 0 — len(dict) is how you track "distinct"; a stale zero-count key poisons it.
  3. "Fruits into baskets" = "K distinct" with K=2 — same pattern, different costume. Don't be fooled by the story.
Ba cái chết người: (1) co bằng while chứ không phải if; (2) nhớ del key khi count về 0 kẻo đếm distinct sai; (3) "Fruits into baskets" chỉ là K distinct với K=2 — cùng bài, khác vỏ.
