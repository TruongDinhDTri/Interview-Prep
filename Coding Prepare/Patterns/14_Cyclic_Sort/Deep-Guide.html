Pattern 14

CyclicSort.

One core idea — every number has a home address. Send each one home, and the empty seats reveal the answer. Press step and watch.

The core idea

Every number knows its seat.

When an array of size N holds the numbers 1…N (or 0…N−1), there's a perfect one-to-one match: value X belongs at index X−1. That hidden structure means you can sort with no comparisons — just by sending each number to its seat.

Walk the array. If the number at your hand isn't home, swap it to its seat (kicking out whoever sat there) and look at the newcomer. Each number reaches its seat in at most one swap, so the whole thing is O(N).

value X → index X−1; swap everyone home in one pass. After sorting, any seat holding the wrong number screams the answer: that index's rightful number is missing, and the impostor sitting there is the duplicate.

Shape one of two

① Place into home — the sort itself.

Swap to seat

Place into home

Pointer i scans. If nums[i] isn't already home, swap it there. Don't advance i after a swap — examine the newcomer that just landed under you first.

The idea

The guard is nums[i] != nums[correct], not nums[i] != i+1 — comparing the two seats' contents handles duplicates and prevents an infinite swap loop (when two equal values both want the same seat). Only when the current value is already home do you move i forward.

The movement — watch each number go home

Sort [3, 1, 5, 4, 2] (values 1…5). Home of X is index X−1.

The code

def cyclic_sort(nums):
    i = 0
    while i < len(nums):
        home = nums[i] - 1                    # X belongs at X-1
        if nums[i] != nums[home]:           # compare CONTENTS, not index
            nums[i], nums[home] = nums[home], nums[i]
            # don't i++ — check who just arrived
        else:
            i += 1

Lives in: sort 1…N in place · the setup step for every missing/duplicate problem.

② Read the gaps — find missing / duplicate.

Scan the wrong seats

Read the gaps

After the place-into-home pass, do one more scan. The first seat whose number doesn't match (nums[i] != i+1) hands you both answers at once.

The idea

If seat i holds the wrong value, then i+1 (the number that should live there) is missing, and the impostor nums[i] is the duplicate. No extra space — the array's own seats encode the answer.

The movement — the empty seat speaks

You own it when…

The test.

  • Core idea in one line: value X lives at index X−1; swap everyone home.
  • You guard with nums[i] != nums[correct] and don't i++ after a swap.
  • You read a wrong seat as “i+1 missing, nums[i] duplicate”.
  • You only reach for this when all three hold: size N · range 1…N · find missing/duplicate.
