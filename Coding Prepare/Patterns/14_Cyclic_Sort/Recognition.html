Pattern 14 · Recognition

Cyclic Sort

⚡ Thẻ nhận diện nhanh — liếc signal là ra bài.

🎯 Spot it

The signals that scream Cyclic Sort.

Array of size N holding numbers in range [1, N] (or [0, N-1]) + asked to "find missing / find duplicate" — the values ARE the indices.

Mảng N phần tử, giá trị nằm gọn trong [1, N], mà đề bảo "tìm số thiếu / số trùng" → giá trị chính là chỉ số → Cyclic Sort.

All THREE must be true:

Array of size N✓ needed
Numbers in range [1, N] or [0, N-1]✓ needed
"Find missing" or "find duplicate"✓ needed
Range huge (10⁹), negatives, or read-only array✗ → not cyclic
Phải đủ cả ba: mảng size N, giá trị trong [1,N] (hoặc [0,N-1]), và đề tìm thiếu/trùng. Thiếu một điều — dải quá lớn, có số âm, hay cấm sửa mảng — thì không phải Cyclic Sort.

⚙️ Why it works

Every number has a home. Number X belongs at index X-1. Swap each number toward its home; once every number sits home, whatever index is wrong reveals the missing / duplicate. O(N) — each number is swapped into place at most once.
Mỗi số có một ô "nhà" cố định (số X về ô X-1). Cứ đổi chỗ đưa từng số về nhà; sau đó ô nào sai chính là chỗ số thiếu/trùng. Mỗi số chỉ đổi chỗ tối đa một lần nên O(N).

💻 The core

The move, in code.

def cyclicSort(nums):
    i = 0
    while i < len(nums):
        correct = nums[i] - 1          # where it should be
        if nums[i] != nums[correct]:    # not home AND target different
            nums[i], nums[correct] = nums[correct], nums[i]
            # DON'T increment - check swapped element
        else:
            i += 1

    # Scan for mismatches
    for i in range(len(nums)):
        if nums[i] != i + 1:
            # i+1 is missing, nums[i] is duplicate
            pass
Vòng lặp: nếu số ở i chưa đúng nhà thì đổi chỗ về nhà (KHÔNG tăng i); đúng nhà rồi mới tiến. Xong quét một lượt — ô nào lệch là lộ số thiếu/trùng.

📐 Index formula

Where does a number go home?

Range [1, N]correct = num - 1
Range [0, N-1]correct = num
Dải bắt đầu từ 1 → nhà của số là ô num - 1. Dải bắt đầu từ 0 → nhà chính là ô num. Nhìn dải trước, chọn công thức sau.

⚠️ Traps

Where it breaks.

  1. Don't increment i after a swap — you must re-check the element that just landed in slot i.
  2. Compare nums[i] != nums[correct], NOT nums[i] != i+1 — this handles duplicates and avoids an infinite loop.
  3. First Missing Positive: filter to the range first with if 1 <= nums[i] <= n.
Ba cái bẫy: (1) đừng tăng i ngay sau khi swap; (2) so nums[i] != nums[correct] chứ không phải với i+1 — tránh vòng lặp vô tận khi có số trùng; (3) bài First Missing Positive phải lọc về dải [1,N] trước.
