Monotonic Stack

A stack with one extra rule: values must stay ordered.
When a newcomer breaks the order — magic happens.

🌱 What Is a Monotonic Stack?

A regular stack stores things in LIFO order — no rules about the values.

A Monotonic Stack adds one extra rule: the values inside must stay in a specific order — either increasing or decreasing from bottom to top.

When a new element breaks that order → you pop everything that violates it before pushing. The pop moment is where you get the answer.

Increasing Stack: popped elements found their Next Smaller Element
Decreasing Stack: popped elements found their Next Greater Element

⛰️ The Two Types

↑ Monotonically Increasing

Bottom → Top: small → big
Pop when: new element is SMALLER than top
Finds: Next Smaller Element

↓ Monotonically Decreasing

Bottom → Top: big → small
Pop when: new element is BIGGER than top
Finds: Next Greater Element

⚙️ The 3 Steps — Every Time a New Element Arrives

Step 1
CHECK
Does it break the stack's order?
Step 2
POP
Pop violators. Each popped element just found its answer.
Step 3
PUSH
Push the new element onto the stack.

📝 Template A — Monotonically Increasing (finds Next Smaller)

↑ Increasing 
stack = []                                              # stores indices
for i in range(len(arr)):
    while stack and arr[i] < arr[stack[-1]]:    # new element SMALLER → pop
        popped_idx = stack.pop()
        # arr[i] IS the Next Smaller Element for arr[popped_idx]
        next_smaller[popped_idx] = arr[i]
    stack.append(i)
# Anything still in stack → has NO next smaller element

📝 Template B — Monotonically Decreasing (finds Next Greater)

↓ Decreasing 
stack = []                                              # stores indices
for i in range(len(arr)):
    while stack and arr[i] > arr[stack[-1]]:    # new element BIGGER → pop
        popped_idx = stack.pop()
        # arr[i] IS the Next Greater Element for arr[popped_idx]
        next_greater[popped_idx] = arr[i]
    stack.append(i)
# Anything still in stack → has NO next greater element

🔄 The Skeleton (both types share this)

for each element:
    while stack not empty AND current element violates the order:
        pop → current element is the answer for the popped element
    push current element

⏱️ Why O(N)? — "Each Element Moves Twice"

Looks like nested loops (for + while). Feels like O(N²). It's actually O(N).

Push
Pop
Total: 9 operations for 6 elements.
Each element is pushed exactly once and popped at most once = 2N = O(N).

⚡ Quick Reference

🔔 See "next greater/smaller" or "wait until X" → Think Monotonic Stack

🏗️ Two Types:
    • Increasing (↑) bottom→top: small→big → finds Next SMALLER
    • Decreasing (↓) bottom→top: big→small → finds Next GREATER

🔄 Which type? OPPOSITE of what you're looking for
    • Want bigger? → Decreasing stack
    • Want smaller? → Increasing stack

⚙️ Each element: Check → Pop violators → Push
📍 The pop moment = "this popped element just found its answer"

⏱️ Time: O(N) — each element pushed once, popped at most once
📦 Space: O(N)

🔍 Live Trace Examples

Study these step-by-step traces to understand how monotonic stacks work.

↑ Increasing Stack Example

Input: [1, 7, 9, 5, 4, 8]
Rule: bottom → top must be ascending. Pop when new element < top.

① 1 arrives → Stack empty, push → [1]

② 7 arrives → 7 > 1, push → [1, 7]

③ 9 arrives → 9 > 7, push → [1, 7, 9]

④ 5 arrives 
   5 < 9 → POP 9 (9 found Next Smaller: 5) ✓
   5 < 7 → POP 7 (7 found Next Smaller: 5) ✓  
   5 > 1 → stop, push 5 → [1, 5]

⑤ 4 arrives
   4 < 5 → POP 5 (5 found Next Smaller: 4) ✓
   4 > 1 → stop, push 4 → [1, 4]

⑥ 8 arrives → 8 > 4, push → [1, 4, 8]

Result: Elements 1, 4, 8 have NO next smaller element

↓ Decreasing Stack Example

Input: [6, 3, 1, 5, 6, 2]
Rule: bottom → top must be descending. Pop when new element > top.

① 6 arrives → Stack empty, push → [6]

② 3 arrives → 3 < 6, push → [6, 3]

③ 1 arrives → 1 < 3, push → [6, 3, 1]

④ 5 arrives
   5 > 1 → POP 1 (1 found Next Greater: 5) ✓
   5 > 3 → POP 3 (3 found Next Greater: 5) ✓
   5 < 6 → stop, push 5 → [6, 5]

⑤ 6 arrives
   6 > 5 → POP 5 (5 found Next Greater: 6) ✓
   6 ≥ 6 → equal OK, push 6 → [6, 6]

⑥ 2 arrives → 2 < 6, push → [6, 6, 2]

Result: Elements 6, 6, 2 have NO next greater element

⚖️ Monotonic vs Regular Stack

Regular Stack

  • No order rule
  • Push anything
  • Matching pairs
  • Valid Parentheses
  • Undo operations
  • Expression evaluation

Monotonic Stack

  • Must stay ordered
  • Pop violators first
  • Next greater/smaller
  • Daily Temperatures
  • Largest Rectangle
  • Stock Span
