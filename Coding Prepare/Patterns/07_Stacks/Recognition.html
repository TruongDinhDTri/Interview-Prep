Stacks

⚡ Thẻ nhận diện nhanh — liếc signal là ra bài.

🎯 Spot it

The signals that scream Stack.

An element must WAIT for a later one to resolve it — last-in, first-out.

Thấy phần tử phải chờ một phần tử sau tới mới "xử" được → Stack. Hai dạng: đóng/mở khớp nhau = Regular; next greater/smaller = Monotonic.
"matching" / "balanced" / "valid parentheses"✓ regular stack
"next greater/smaller" / "previous greater/smaller"✓ monotonic stack
"days until" / "span" / "temperatures"✓ monotonic stack
"pending items" / "wait" / "evaluate in order" / "operator fires on previous"✓ regular stack
"postfix / RPN / evaluate expression"✓ regular stack
Hai họ chung một gốc LIFO. Regular = cái đang mở chờ cái đóng (ngoặc, RPN). Monotonic = phần tử nhỏ chờ một phần tử lớn hơn tới "trả lời" (next greater/smaller).

⚙️ Why it works

Regular: the stack holds "pending" items waiting for their match — ( waits for ), a number waits for its operator (RPN).
Monotonic: the stack holds unresolved elements; when a bigger element arrives, it "answers" all the smaller ones still waiting. Each element is pushed once, popped once → O(N).
Stack chỉ là chỗ giữ những thứ chưa được giải quyết. Cái mới tới đủ điều kiện thì "trả lời" và pop chúng ra. Mỗi phần tử vào-ra đúng một lần nên tổng cộng O(N).

💻 The core

Monotonic stack, in code.

def nextGreater(nums):
    result = [-1] * len(nums)
    stack = []  # indices

    for i, num in enumerate(nums):
        while stack and num > nums[stack[-1]]:
            result[stack.pop()] = num
        stack.append(i)
    return result

Cheat sheet — pick stack order by what you're hunting:

WANT STACK ORDER POP WHEN
Next GreaterDecreasingcurr > top
Next SmallerIncreasingcurr < top
Lưu index chứ không lưu value để còn biết vị trí. Muốn Next Greater thì giữ stack giảm dần, phần tử lớn hơn tới thì pop và "trả lời".

⚠️ Traps

Where it breaks.

  1. Store INDICES, not values — you'll need the positions later.
  2. Always check stack and … before comparing to the top — empty stack crashes.
  3. Greater → Decreasing stack, Smaller → Increasing stack.
Ba cái chết người: (1) lưu value thay vì index; (2) quên stack and → lỗi khi stack rỗng; (3) lộn chiều: Greater dùng stack giảm, Smaller dùng stack tăng.

🧮 Regular stack — RPN

Evaluate postfix (LeetCode #150).

ops = {
    "+": lambda a, b: a + b,
    "-": lambda a, b: a - b,
    "*": lambda a, b: a * b,
    "/": lambda a, b: int(a / b),  # truncate toward zero, NOT //
}
stack = []
for token in tokens:
    if token not in ops:
        stack.append(int(token))
    else:
        first_num  = stack.pop()   # RIGHT operand
        second_num = stack.pop()   # LEFT operand
        stack.append(ops[token](second_num, first_num))  # LEFT op RIGHT ← order matters!
return stack.pop()
  1. isdigit() fails on "-11" → use token not in ops instead.
  2. Operand order: second_num op first_num (LEFT op RIGHT), NOT reversed.
  3. Division: int(a/b) truncates toward zero; a//b is floor — different for negatives.
  4. Use a list, not deque — .append() + .pop() is already O(1).
RPN: gặp số thì push, gặp phép toán thì pop hai lần — nhớ cái pop đầu là toán hạng PHẢI. Chia phải int(a/b) (cắt về 0), không dùng //.
