🍃 The asymmetry — the whole secret

🔴 Hit a 0 → swap with left

The value pulled under mid comes from BEHIND — territory the scanner already walked (all whites). It's already checked.
→ mid STRIDES forward (mid++), and left++.

🔵 Hit a 2 → swap with right

The value pulled under mid comes from the UNEXPLORED right zone — the scanner has never seen it.
→ mid STAYS PUT to re-examine the newcomer; only right--.

White (1)? It already belongs in the middle — just step over it: mid++. Loop runs while mid <= right — the = is what processes the very last slot (test [1,0] to see why < fails!).

🪣 Contrast — the two-pass Counting Sort

When the value-set is tiny, skip swapping entirely: tally the counts, then paint the array back in the order YOU choose. Sorted order comes from your write-order, not from the dict.

show counting-sort code 
# Pass 1: tally. Pass 2: paint with ONE shared cursor.
from collections import Counter
def sortColors(nums):
    c = Counter(nums)
    i = 0
    for v in (0, 1, 2):        # WE choose the order
        for _ in range(c[v]):
            nums[i] = v
            i += 1              # one cursor marching — never reset
