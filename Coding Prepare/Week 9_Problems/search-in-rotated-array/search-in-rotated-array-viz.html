The Engine

Why every line exists 🔧

The whole algorithm is just the invariant, made literal:

class Solution:
    def search(self, nums, target):
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right) // 2
            if nums[mid] == target:
                return mid

            # ① WHICH half is the sorted one? (the invariant guarantees ≥1 is)
            if nums[left] <= nums[mid]:          # left half is sorted
                # ② only NOW can I trust a range check — on the sorted half
                if nums[left] <= target < nums[mid]:
                    right = mid - 1             # target lives here → hunt left
                else:
                    left = mid + 1              # can't be here → throw left away
            else:                              # right half is sorted
                if nums[mid] < target <= nums[right]:
                    left = mid + 1              # target lives here → hunt right
                else:
                    right = mid - 1             # can't be here → throw right away
        return -1

Time O(log n) — still halving every step. Space O(1). BTTC for a sorted search is O(log n) → already optimal.
