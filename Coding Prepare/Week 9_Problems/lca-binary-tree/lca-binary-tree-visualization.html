🔥 The 5 Rules (Discovered From Tracing)

Rule 1 — Base (null)
if current == None
    return None
Rule 2 — Base (self-match)
if current == p or current == q
    return current
Rule 3 — Recurse
left  = dfs(current.left)
right = dfs(current.right)
Rule 4 — LCA Born ⭐
if left and right
    return current
Rule 5 — Bubble Up
return left if left else right
# only one non-None → pass it up
# both None → returns None (combined)

💡 Why the Mechanism is Signal-Agnostic

The parent receives at most one non-None value from each subtree. It cannot tell if that non-None is:

  • 🍊 a target node (Case 2)
  • 🌕 the LCA itself already discovered below (Case 5)
  • 🟡 a relayed signal bubbling up through ancestors (Case 4)

And it doesn't need to. All three look identical. The combine rule — "both non-None → I'm the LCA, else bubble what I have" — works for every case without distinguishing.
