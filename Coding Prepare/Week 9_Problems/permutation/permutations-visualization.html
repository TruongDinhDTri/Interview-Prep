🔥 The 3 Rules (Discovered From the Decision Tree)

🌿

Rule 1 — Pick

Loop ALL nums, skip if num in used. Add to path AND used set.

🍃

Rule 2 — Base Case

When len(path) == len(nums), the path is a complete permutation. Record it.

🔄

Rule 3 — Unpick

After recursing, path.pop() and used.remove(num) to restore parent state.

The algorithm starts at the root with an empty path. At each node, it loops through all numbers and picks one that is not yet in the used set. After recursing, it unpicks — removing from both path and used — so the next sibling can try a different number.
💻 Final Solution
class Solution:
    def permute(self, nums):
        path   = []
        result = []
        used   = set()

        def backtrack(path, used, nums):
            # Rule 2: base case — path is full
            if len(path) == len(nums):
                result.append(list(path))  # copy!
                return

            for num in nums:
                if num not in used:      # Rule 1: pick remaining
                    path.append(num)       # PICK
                    used.add(num)
                    backtrack(path, used, nums)
                    path.pop()             # UNPICK (Rule 3)
                    used.remove(num)       # UNPICK (Rule 3)

        backtrack(path, used, nums)
        return result
📊 Complexity Analysis
DimensionComplexityReasoning
⏱ Time O(n × n!) n! permutations at the leaves × O(n) per copy
📦 Space (aux) O(n) Recursion stack depth n + path (≤n) + used set (≤n)
🎯 BTTC O(n × n!) Can't skip any permutation — must visit all of them
