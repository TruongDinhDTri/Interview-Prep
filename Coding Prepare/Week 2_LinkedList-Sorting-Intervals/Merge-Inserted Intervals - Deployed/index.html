What are Interval Problems?

Interval problems involve working with ranges of values, represented as pairs [start, end]. These problems commonly appear in scheduling applications, time management systems, and range-based queries.

Common Patterns:

  • Merge Intervals: Combine overlapping intervals into non-overlapping ones
  • Insert Interval: Add a new interval and merge if necessary
  • Interval Intersection: Find common ranges between interval lists
  • Remove Covered Intervals: Eliminate intervals contained within others

Key Technique: Sort intervals by start time, then iterate through to identify overlaps

Time Complexity: Typically O(n log n) due to sorting

Applications: Meeting room scheduling, calendar applications, CPU task scheduling, network packet handling
