What is a Linked List?

A linked list is a linear data structure where elements (nodes) are connected using pointers. Each node contains data and a reference to the next node in the sequence. Unlike arrays, linked lists don't require contiguous memory allocation.

Types: Singly Linked List, Doubly Linked List, Circular Linked List

Key Operations:

  • Insertion: O(1) at head, O(n) at specific position
  • Deletion: O(1) at head, O(n) at specific position
  • Search: O(n)
  • Traversal: O(n)

Common Problems: Reversing lists, detecting cycles, merging sorted lists, finding middle element, removing duplicates
