🔄 Cyclic Sort Pattern

In-Place Sorting for Continuous Ranges

💡 What is Cyclic Sort?

Cyclic Sort is a brilliant pattern for dealing with problems involving arrays containing numbers in a given range. Instead of traditional sorting (O(n log n)), we achieve O(n) time by placing each number at its correct index!

Perfect for: Finding missing numbers, duplicates, or smallest missing positive in arrays with continuous ranges like [1...n] or [0...n-1].

🔥 Key Insight

The Magic: If you have numbers from 1 to n, number 1 should go to index 0, number 2 to index 1, etc. We keep swapping each number to its correct position until everything is in place!

Time: O(n) - each number moves to its position at most once
Space: O(1) - in-place sorting!
