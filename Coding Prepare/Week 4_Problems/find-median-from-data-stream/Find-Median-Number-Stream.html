"Find the Median of a Number Stream"

The Question

Numbers keep arriving one by one.
After each number someone asks:
"What's the median right now?"

❌

Sort after every insert

O(n log n) per number — unusable on large streams.

✅

Two Heaps

O(log n) insert · O(1) median. Only track the middle.

The Two-Bucket Split

Split numbers into two groups. Keep them balanced. The median hides at the boundary.

The median lives right between the two roots

Every Time a Number Arrives — 3 Steps

1

Put it in the right bucket

Left empty → Left  ·  num ≤ Left root → Left  ·  num > Left root → Right

2

If one side is too big → move its root to the other side

Left has 2+ extra → move Left root Right  ·  Right bigger → move Right root Left

3

Read the median from the roots

Equal size → (Left root + Right root) / 2  ·  Left has +1 → Left root

The Solution

Two Heaps · Find the Median from a Number Stream

solution.py
from heapq import *

class Solution:
def __init__(self):
# max-heap (left) — negate values; Python only has min-heap
self.left  = []
# min-heap (right) — values as-is
self.right = []

def insertNum(self, num):
# ① route to the right bucket
if self.left == []:
heappush(self.left, -num)
elif num <= -self.left[0]:
heappush(self.left, -num)
else:
heappush(self.right, num)

# ② rebalance sizes
if len(self.left) - len(self.right) > 1:
heappush(self.right, -heappop(self.left))
elif len(self.left) < len(self.right):
heappush(self.left, -heappop(self.right))

def findMedian(self):
# ③ read the median
if len(self.right) == len(self.left):
return ((-self.left[0]) + (self.right[0])) / 2
return -self.left[0] / 1.0

Time Complexity

insertNum() O(log n)
findMedian() O(1)

At most 2 heap ops per insert (push + rebalance)

Space Complexity

Total O(n)

All n numbers stored across both heaps

Why not just sort each time?

Sort = O(n log n) per insert. Two Heaps = O(log n). At 1,000,000 numbers the difference is massive.
