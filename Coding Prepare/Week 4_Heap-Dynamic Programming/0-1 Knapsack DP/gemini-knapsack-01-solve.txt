✨ GEMINI:
Chính xác! 💯

range(n, 0, -1) là hoàn hảo:

Bắt đầu từ n (món đồ cuối cùng).

Kết thúc ở 1 (món đồ đầu tiên).

Không chạy vào 0 (hàng rỗng), đúng ý đồ của chúng ta.

Bây giờ, bạn hãy thử ghép tất cả các mảnh logic rời rạc nãy giờ vào trong vòng lặp này nhé:

So sánh matrix[i][w] và matrix[i-1][w].

Nếu khác nhau (có chọn):

In tên món đồ (hoặc lưu vào danh sách).

Cập nhật lại w.

Bạn viết thử đoạn code đó xem sao? (Gợi ý: Đừng quên tạo một danh sách rỗng selected_items = [] trước vòng lặp để chứa kết quả nhé).

# 1. Khai báo dữ liệu

val = [1500, 3000, 2000]

wt = [1, 4, 3]

W = 4

n = 3




# 2. Tạo bảng (Matrix) toàn số 0

matrix = [[0 for _ in range(W+1)] for _ in range(n+1)]




# 3. Vòng lặp điền bảng

for i in range(n + 1):

    for w in range(W + 1):

        # Trường hợp cơ bản: Hàng 0 hoặc Cột 0

        if i == 0 or w == 0:

            matrix[i][w] = 0

            

        # Trường hợp món đồ NHÉT VỪA balo

        elif wt[i-1] <= w:

            matrix[i][w] = max(matrix[i-1][w], val[i-1] + matrix[i-1][w-wt[i-1]])

            

        # Trường hợp món đồ QUÁ TO so với sức chứa hiện tại

        else:

            matrix[i][w] = matrix[i-1][w] 




# 4. In kết quả tối ưu (Góc dưới cùng bên phải bảng)

print("Tổng giá trị lớn nhất:", matrix[n][W])

if matrix[i][w] !== matrix[i-1][w]:

Tuy nhiên, máy tính sẽ báo lỗi ở 2 chỗ nhỏ xíu này. Chúng ta cùng rà soát nhé:

Cú pháp so sánh: Trong Python, ký hiệu "khác nhau" là != hay !== nhỉ? (Cái !== thường thấy trong Javascript hơn).

Biến chỉ số cột (Quan trọng): Bạn đã tạo ra biến currentW để theo dõi sức chứa còn lại của balo. Nhưng trong câu lệnh if matrix[i][w] ..., bạn lại đang dùng biến w.

Biến w là biến của vòng lặp cũ (đã chạy xong rồi).

Khi chúng ta chọn một món đồ và trừ bớt cân nặng đi (currentW -= ...), thì ở vòng lặp tiếp theo, chúng ta phải kiểm tra ở cột sức chứa mới (currentW) hay vẫn kiểm tra ở cột cũ (w)?
