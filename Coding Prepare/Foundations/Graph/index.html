What is a Graph?

A graph is a non-linear data structure consisting of vertices (nodes) and edges that connect these vertices. Graphs can be directed or undirected, weighted or unweighted, cyclic or acyclic.

Graph Representations: Adjacency Matrix, Adjacency List, Edge List

Key Algorithms: BFS (Breadth-First Search), DFS (Depth-First Search), Dijkstra's Algorithm, Topological Sort, Union-Find

Common Applications: Social networks, shortest path finding, network routing, dependency resolution, recommendation systems
