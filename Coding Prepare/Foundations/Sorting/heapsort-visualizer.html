🏔️ The Mountain Metaphor: Imagine building a mountain range where parent peaks are always taller than their child peaks (max heap property)! First, we build the heap by ensuring every parent is at the peak. Then, we repeatedly swap the tallest peak (root) to the end and rebuild the heap with the remaining elements. The sorted array emerges from tallest to shortest!

def heap_sort(arr):
    n = len(arr)
    # Build max heap
    for i in range(n//2-1, -1, -1):
        heapify(arr, n, i)
    # Extract elements one by one
    for i in range(n-1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]
        heapify(arr, i, 0)
def heapify(arr, n, i):
    largest = i
    left = 2*i+1
    right = 2*i+2
    if left < n and arr[left] > arr[largest]:
        largest = left
    if right < n and arr[right] > arr[largest]:
        largest = right
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)
# Time: O(n log n)
# Space: O(1) in-place
