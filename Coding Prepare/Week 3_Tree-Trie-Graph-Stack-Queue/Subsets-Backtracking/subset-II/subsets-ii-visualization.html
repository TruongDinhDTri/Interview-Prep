🔥 Key Insight: Why Skip Duplicates in EXCLUDE Branch?

  • When you INCLUDE element A → You might later EXCLUDE duplicate B → Creates subset with A
  • When you EXCLUDE element A → If you INCLUDE duplicate B → Creates SAME subset!
  • Solution: If you EXCLUDE an element, skip ALL consecutive duplicates
  • Precondition: Array must be SORTED so duplicates are neighbors!
