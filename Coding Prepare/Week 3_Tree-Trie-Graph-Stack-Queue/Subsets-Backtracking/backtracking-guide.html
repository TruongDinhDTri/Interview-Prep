🔄 Backtracking

One pattern. Three questions. Kill any interview.

🔑 The Deep Idea
Thử mọi con đường có thể.
Đi hết một con đường → tẩy về ngã tư → thử con đường khác.

Imagine a maze 🏃‍♂️ — you walk down a corridor. Dead end? Walk back to the last fork, try another corridor. That's it. That's backtracking.

The "back" in backtracking = the undo step. Without it, your state is dirty and the next attempt sees wrong data.

Signal words: "find all", "generate all", "all possible", "every combination/permutation"
→ Backtracking.
❓ The 3 Questions — Gặp bài nào cũng hỏi

Every backtracking problem is defined by answering exactly 3 questions. The template stays the same — only these answers change.

🎯
CHOICE — "Tao chọn gì?"
What options are available at this step? Loop through nums? Candidates? 0 to n?
🚧
CONSTRAINT — "Valid không?"
What makes a choice invalid? Already used? Exceeds target? Skip duplicates?
🏁
GOAL — "Done chưa?"
When is a solution complete? Path full? Budget = 0? Every state?

Subsetsnums[start:]noneevery node
Permutationsall numsnot in usedlen == n
Combinationsnums[start:]nonelen == k

💻 The Template

Every backtracking problem fits this skeleton. Just swap the 3 answers.

def backtrack(state): # ─── GOAL: done chưa? ─── if goal_reached(state): result.append(state.copy()) # ⚠️ always copy! return # ─── CHOICE: chọn gì? ─── for option in choices: # ─── CONSTRAINT: valid không? ─── if is_valid(option): pick(option) # ✏️ vẽ backtrack(new_state) # đi sâu (trust this) unpick(option) # 🧹 tẩy — về ngã tư
Remember: pick = vẽ con đường. unpick = tẩy về ngã tư.
Nếu không tẩy → state bẩn → iteration kế thấy sai → kết quả sai.

🧭 The Idea Flow
START with empty path [] → GOAL: Done? (base case check) YES → save result (copy!), return NO → continue ↓ → CHOICE: Loop through options → CONSTRAINT: Valid? NO → skip YES → ↓ → ✏️ Pick(option) → 🔽 Recurse — go deeper (trust it) → 🧹 Unpick(option) — tẩy về ngã tư → Try next option... → All options tried → return (go back up one level)

🎯 The 3 Decisions That Change Everything

ONE template. Only 3 things change between problems:

Decision 1: When is it "complete"? (GOAL)
• Subsets → ALWAYS. Save BEFORE the loop.
• Permutations → When len == n. Use ALL elements.
• Combinations → When len == k. Exactly k.
• Combo Sum → When remaining == 0. Hit target.
Decision 2: Available choices? (CHOICE)
• Subsets / Combinations / Combo Sum → start index. Only forward.
• Permutations → From 0 every time. Skip used.
Decision 3: Reuse? (CONSTRAINT)
• NO → recurse with i + 1
• YES (Combo Sum) → recurse with i

🔪 Duplicate Handling

When input has duplicates like [1, 2, 2, 3]:

1Sort the array first
2Skip if current == previous at same level: if i > start and nums[i] == nums[i-1]: continue
🚨 Interview Checklist
  • "Find all" / "generate all"? → Backtracking
  • Ask the 3 Questions: CHOICE, CONSTRAINT, GOAL
  • Can elements be reused? → backtrack(i) vs backtrack(i+1)
  • Does order matter? → Permutation vs Combination
  • Duplicates in input? → Sort + skip
  • Always .copy() when saving
  • Always undo (unpick) after exploring
🗣️ Say-It-Out-Loud
"Backtracking explores all possible solutions by building one piece at a time. At each step I ask 3 questions: what are my CHOICES, which are VALID (constraint), and am I DONE (goal). I pick a valid option, recurse deeper, then UNDO the pick to try alternatives. The template is always the same — only the 3 answers change between problems."

def subsets(nums): result = [] def backtrack(start, current): result.append(current.copy()) # save BEFORE loop for i in range(start, len(nums)): current.append(nums[i]) # CHOOSE backtrack(i + 1, current) # EXPLORE current.pop() # UN-CHOOSE backtrack(0, []) return result

Duplicates (LC 90): Sort + if i > start and nums[i] == nums[i-1]: continue

def permute(nums): result, used = [], [False] * len(nums) def backtrack(current): if len(current) == len(nums): result.append(current.copy()); return for i in range(len(nums)): if used[i]: continue used[i] = True; current.append(nums[i]) backtrack(current) current.pop(); used[i] = False backtrack([]); return result

def combine(n, k): result = [] def backtrack(start, current): if len(current) == k: result.append(current.copy()); return for i in range(start, n + 1): current.append(i) backtrack(i + 1, current) current.pop() backtrack(1, []); return result

def combinationSum(candidates, target): result = [] def backtrack(start, current, remaining): if remaining == 0: result.append(current.copy()); return if remaining < 0: return # PRUNE for i in range(start, len(candidates)): current.append(candidates[i]) backtrack(i, current, remaining - candidates[i]) # i = reuse current.pop() backtrack(0, [], target); return result
