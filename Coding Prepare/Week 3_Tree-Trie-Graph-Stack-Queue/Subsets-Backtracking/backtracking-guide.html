🔄 Backtracking

One pattern. Three rules. Kill any interview.

🔑 What Is Backtracking?
Backtracking = Recursion + "undo". One single pattern. Not 4 techniques — just ONE core engine applied to different problem shapes.

Like walking a maze 🏃‍♂️ — try a path, hit dead end, walk back to the fork, try another path.

Used when problem says: "find all", "generate all", "all possible", "every combination".

⏱ Time Complexity
Problem typeBig-O
SubsetsO(2^n)
PermutationsO(n!)
CombinationsO(C(n,k))
🧱 The ONE Core Idea

Build a solution piece by piece, and undo when a piece doesn't work.

Like building a LEGO tower 🧱 — place a block, keep going up. Tower wobbles? Remove the last block → try a different one.

📏 The 3 Rules (NEVER break these)
1CHOOSE — Pick one option. Add it to your current candidate.
2EXPLORE — Recurse deeper with that choice. See where it leads.
3UN-CHOOSE — After exploring, remove that choice. Now you're clean to try the next.
⚠COPY — When saving a solution, always .copy() it. Your candidate is mutated in-place.
🔄 The Idea Flow
START with empty candidate [] → Is this a complete solution? YES → save it (copy!), return NO → continue ↓ → Loop through available choices: → Pick choice X (CHOOSE) → Go deeper with X (EXPLORE) → Remove X (UN-CHOOSE) → Pick choice Y (next iteration) → Go deeper with Y (EXPLORE) → Remove Y (UN-CHOOSE) → Return (this level is done, go back up)

It's like a tree. Each level = one decision. Each branch = one choice. Walk down every branch, and clean up after yourself when you come back up.

💻 Generic Template
def backtrack(candidate, choices, result): if is_solution(candidate): result.append(candidate.copy()) # ⚠️ COPY! return for choice in choices: candidate.append(choice) # Rule 1: CHOOSE backtrack(candidate, next_choices, result) # Rule 2: EXPLORE candidate.pop() # Rule 3: UN-CHOOSE
🎯 The 3 Decisions That Change Everything

The ONE pattern handles ALL problems. Only 3 things change:

Decision 1: When is it "complete"?
• Subsets → ALWAYS. Save BEFORE the loop.
• Permutations → When len == n. Use ALL elements.
• Combinations → When len == k. Exactly k.
• Combo Sum → When remaining == 0. Hit target.
Decision 2: Available choices?
• Subsets / Combinations / Combo Sum → start index. Only forward.
• Permutations → From 0 every time. Skip used.
Decision 3: Reuse?
• NO → recurse with i + 1
• YES (Combo Sum) → recurse with i

🔪 Duplicate Handling

When input has duplicates like [1, 2, 2, 3]:

1Sort the array first
2Skip if current == previous at same level: if i > start and nums[i] == nums[i-1]: continue
🚨 Interview Checklist
  • "Find all" / "generate all"? → Backtracking
  • Can elements be reused? → backtrack(i) vs backtrack(i+1)
  • Does order matter? → Permutation vs Combination
  • Duplicates in input? → Sort + skip
  • What makes a solution complete? → That's your base case
  • Always .copy() when saving
  • Always undo after exploring
🗣️ Say-It-Out-Loud
"Backtracking is a recursive pattern where I build a solution incrementally. At each step I make a choice, recurse to explore that path, then undo the choice to try alternatives. The key decisions are: when is a solution complete, what choices are available, and can I reuse elements. Everything else is the same pattern with different answers to those 3 questions."

def subsets(nums): result = [] def backtrack(start, current): result.append(current.copy()) # save BEFORE loop for i in range(start, len(nums)): current.append(nums[i]) # CHOOSE backtrack(i + 1, current) # EXPLORE current.pop() # UN-CHOOSE backtrack(0, []) return result

Duplicates (LC 90): Sort + if i > start and nums[i] == nums[i-1]: continue

💻 Code
def permute(nums): result, used = [], [False] * len(nums) def backtrack(current): if len(current) == len(nums): result.append(current.copy()); return for i in range(len(nums)): if used[i]: continue used[i] = True; current.append(nums[i]) backtrack(current) current.pop(); used[i] = False backtrack([]); return result

def combine(n, k): result = [] def backtrack(start, current): if len(current) == k: result.append(current.copy()); return for i in range(start, n + 1): current.append(i) backtrack(i + 1, current) current.pop() backtrack(1, []); return result

def combinationSum(candidates, target): result = [] def backtrack(start, current, remaining): if remaining == 0: result.append(current.copy()); return if remaining < 0: return # PRUNE for i in range(start, len(candidates)): current.append(candidates[i]) backtrack(i, current, remaining - candidates[i]) # i = reuse current.pop() backtrack(0, [], target); return result
