What are Matrix Problems?

Matrix problems involve working with 2D arrays and grids. These problems are fundamental in computer science and appear frequently in coding interviews. They often combine graph algorithms with 2D array manipulation.

Common Techniques: BFS/DFS on grids, dynamic programming on matrices, matrix traversal patterns (spiral, diagonal), in-place modifications

Key Patterns: Distance calculations, shortest paths in grids, flood fill, island counting, matrix rotation/transformation

Applications: Image processing, game boards, geographical data, pathfinding in maps
