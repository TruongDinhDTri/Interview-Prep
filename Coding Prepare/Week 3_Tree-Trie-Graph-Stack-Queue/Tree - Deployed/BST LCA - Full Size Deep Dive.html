Lowest Common Ancestor in BST

Deep Understanding of the "Split Point"

⚡ The Split Point - Deep Dive

Core Question at Every Node:

"Are p and q in the SAME subtree or DIFFERENT subtrees?"

⬅️⬅️
Scenario 1: Both Go LEFT

Condition: p < current AND q < current

Meaning: Both p and q exist in the LEFT subtree

Why NOT the LCA?

If both are in the left subtree, then there's a node DEEPER in that left subtree that also contains both. Current node is a common ancestor, but NOT the lowest one. We need to go down into the left subtree to find a more specific (lower) ancestor.

→ Move to current.left

➡️➡️
Scenario 2: Both Go RIGHT

Condition: p > current AND q > current

Meaning: Both p and q exist in the RIGHT subtree

Why NOT the LCA?

Same logic as above. If both are in the right subtree, then there's a node DEEPER in that right subtree that also contains both. Current node is too high - we can find a more specific (lower) common ancestor by going deeper.

→ Move to current.right

⬅️➡️
Scenario 3: THE SPLIT ⚡

Condition: One of these is true:

  • • p < current AND q > current
  • • p > current AND q < current
  • • current == p OR current == q

Meaning: p and q are in DIFFERENT subtrees (or current IS one of them)

Why IS this the LCA? 🎯

1. This is the LAST common point

Before this node, we were coming down a single path. At this node, p and q now diverge into separate branches. This is the fork in the road.

2. No lower node can contain both

If we go left, we only have access to the left subtree (can't reach right subtree). If we go right, we only have access to the right subtree (can't reach left subtree). Since p and q are now separated, NO descendant can be ancestor of both.

3. Tree structure guarantees this

In a tree, a node in the left subtree has NO path to a node in the right subtree without going through their common parent. The split point IS that parent.

✓ Current node contains both in its tree

✓ No child of current contains both

= LOWEST Common Ancestor

→ RETURN current (This is the LCA!)

🌊 Think of it like a River

Upstream (root): Water flows together in one stream

The split point: River forks into two separate branches

Downstream: Two separate streams that never meet again

The fork is the LAST point where both streams share the same water. That's the LCA.

Algorithm

def lowestCommonAncestor(root, p, q):
    current = root
    
    while current:
        # Both in right subtree - go deeper right
        if p.val > current.val and q.val > current.val:
            current = current.right
        
        # Both in left subtree - go deeper left
        elif p.val < current.val and q.val < current.val:
            current = current.left
        
        # They split OR current is one of them
        # = This IS the LCA
        else:
            return current
Time: O(log N)
One node per level
Space: O(1)
No extra memory

Example 1: p=2, q=8

At node 6:

Check p: 2 < 6 → p is in LEFT subtree

Check q: 8 > 6 → q is in RIGHT subtree

⚡ THE SPLIT HAPPENS HERE!

One goes left, one goes right. They're now in DIFFERENT subtrees. This is the last common point before they separate.

✓ LCA = 6

Why can't we go lower?

If we go to node 2 (left), we lose access to node 8 (right). If we go to node 8 (right), we lose access to node 2 (left). No child contains both.

Example 2: p=7, q=9

Step 1 - At node 6:

Check p: 7 > 6 → p is in RIGHT

Check q: 9 > 6 → q is in RIGHT

Both go RIGHT → Same subtree, NOT split yet

Why not the LCA yet?

Both 7 and 9 exist in the right subtree of 6. This means there's a lower node (inside that right subtree) that also contains both. Node 6 is too high up.

Step 2 - At node 8:

Check p: 7 < 8 → p is in LEFT

Check q: 9 > 8 → q is in RIGHT

⚡ NOW THEY SPLIT!

At node 8, p and q diverge into different subtrees. This is where their paths separate. No node below 8 contains both.

✓ LCA = 8

Example 3: p=7, q=6

At node 6:

Current node = 6

Target q = 6

Current IS one of the targets!

⚡ Special Split Case

When current node equals p or q, it's automatically the LCA. Why? Because one target IS this node, and the other target is somewhere in its subtree. No descendant of node 6 can be an ancestor of node 6 itself.

✓ LCA = 6

🎯 The Essential Truth About Split Points

Before the split: Both nodes are traveling together in the same direction (same subtree). We can go lower and still find a node that contains both.

At the split: The paths diverge. One goes left, one goes right. This is the LAST node where both paths are together. This is the fork. This is the LOWEST point where both are contained.

After the split: They're in separate subtrees. No single node below can contain both because tree structure prevents a left subtree node from reaching a right subtree node without going back up through the split point.

The split = The lowest common point = The LCA ✨
