🔑 Key Insight:

EVERY node gets swapped, even leaf nodes! When we reach a leaf (like node 1, 3, 6, or 9), we still:

  1. Call invertTree(left) → returns because left is null
  2. Call invertTree(right) → returns because right is null
  3. SWAP null ↔ null (nothing visible happens, but the swap still executes!)
  4. Return to the parent node

💡 The algorithm visits EVERY node and swaps at EVERY node, including leaves. The recursion goes down, swapping happens on the way back up!
