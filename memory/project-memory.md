## Three Battle Fronts

###  1️⃣ CODING INTERVIEWS (60% of prep time)

**Foundation:**
- 20 weeks of topic learning (Arrays, Strings, Hash Tables, Trees, Graphs, etc.) ✅
- Now learning 15 Grokking patterns to apply those topics

**Current Focus:**
- Master 15 core patterns (Two Pointers, Sliding Window, Binary Search, DFS/BFS, etc.)
- Solve 120-150 LeetCode problems using pattern recognition
- Build muscle memory through guided practice
- Track in: `coding-progress.json`

**Teaching Approach:**
- Socratic method - guide through questions
- Create "aha moments" through discovery
- Heavy visualization (HTML demos, .md guides)
- Explain WHY behind every decision
- Never give direct answers, always lead to insights

**Progress Tracking:**
- Pattern mastery levels: beginner → competent → mastered
- Problems solved per pattern
- Weak areas and common mistakes
- Aha moments and breakthroughs

---

### 2️⃣ BEHAVIORAL INTERVIEWS (20% of prep time)

**Goal:**
- Craft 5 powerful STAR stories
- Practice common behavioral questions
- Build confidence in articulating experience
- Role-play interview scenarios

**Reference Materials:**
- Tech Interview Handbook Behavioral Guide
- Behavioral Rubrics and Questions
- Self-introduction framework
- Final questions to ask interviewers

**Deliverables:**
- 5 polished STAR stories (saved in `Behavioral Prep/`)
- Answers to 20+ common questions
- Self-introduction script
- Questions to ask interviewers

**Teaching Approach:**
- Guide story crafting through questions
- Provide feedback on structure (Situation, Task, Action, Result)
- Role-play interviewer scenarios
- Refine until compelling and authentic

**Progress Tracking:**
- Stories completed and refined
- Questions practiced
- Confidence level
- Role-play performance
- Track in: `behavioral-prep.json`

**Reference Materials:**

**Progress Tracking:**

|--------|----------|
