LSP gãy: Square không thay được Rectangle

Cùng một hàm f() gọi setWidth rồi setHeight. Rectangle giữ đúng hợp đồng; Square phá nó. Kéo thanh và bấm chạy để thấy tận mắt.

📜 Hợp đồng mà mọi client TIN vào (của Rectangle)
function f(r) {
  r.setWidth(5); r.setHeight(4);
  // đổi width KHÔNG được đụng height
  assert r.area() === 5 * 4 === 20;
}

🟩 Rectangle — giữ hợp đồng

width = 5 · height = 4
area() = 20
chưa chạy

🟧 Square extends Rectangle — phá hợp đồng

width = 5 · height = 5
area() = 25
chưa chạy
Vì sao Square phá LSP: Square buộc setWidth(w) phải đặt luôn height = w (để giữ tính "vuông"). Nhưng hàm f() — viết cho Rectangle — TIN rằng đổi width không đụng height. Khi anh lén đưa Square vào chỗ Rectangle, f() tính sai. Client bị "phản bội" → phải if (instanceof Square) để né → abstraction vô dụng. Bài học: con phải giữ được HỢP ĐỒNG của cha, không chỉ cùng tên method.
Kéo width khác 4 → Square luôn FAIL. Chỉ khi width = height = 4 hai bên mới tình cờ bằng nhau. 🎭
